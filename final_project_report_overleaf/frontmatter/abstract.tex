\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Digital onboarding in financial systems is increasingly vulnerable to synthetic identity attacks, face swaps, replay attacks, and manipulated documents. This project presents an implementation-focused AI-enabled electronic Know Your Customer (eKYC) platform titled \textbf{\projecttitle}. The system is built as a full-stack application with a React TypeScript frontend, FastAPI backend, PostgreSQL/SQLite data layer, MongoDB audit trail storage, and Redis-assisted caching/rate limiting.

The verification workflow includes multi-stage document processing, face comparison, deepfake risk estimation, liveness verification, policy-based decisioning, and admin review for flagged cases. The implementation supports secure authentication, role-based controls, structured API contracts, report generation, and traceable workflow states.

This report documents the complete software engineering lifecycle for the implemented system: problem analysis, requirement specification, design models, coding architecture, test evidence, security controls, observed limitations, and future enhancement paths. The project emphasizes practical deployment behavior and module-level traceability instead of generic theoretical discussion.

\textbf{Keywords:} eKYC, Deepfake Detection, Liveness Detection, Face Verification, FastAPI, React, Identity Verification, Admin Review Workflow.
