# IGNOU Final Submission Checklist

## Mandatory documents

- [ ] Approved project proposal proforma (original)
- [ ] Approved synopsis
- [ ] Guide biodata with signature and date
- [ ] Certificate of originality with signatures
- [ ] Final project report PDF (single consolidated file)

## Report content checklist (project-specific)

- [ ] Table of contents with page numbering
- [ ] Introduction and objectives
- [ ] System analysis and need identification
- [ ] Project planning + PERT + Gantt
- [ ] SRS
- [ ] Engineering paradigm used
- [ ] DFD/ER/use-case/class/sequence/activity/state/control-flow diagrams
- [ ] System design and modularization
- [ ] Data integrity and DB constraints
- [ ] UI design
- [ ] Unit + system test cases and reports
- [ ] Coding standards, validation, error handling
- [ ] Security implementation and user access rights
- [ ] Sample reports/output layouts
- [ ] Future scope
- [ ] Bibliography
- [ ] Appendix and glossary

## Final consistency checks

- [ ] Project title exactly matches approved synopsis title everywhere
- [ ] All figures/tables numbered and captioned
- [ ] Content is implementation-specific, not generic textbook material
- [ ] PDF generated and validated before upload
